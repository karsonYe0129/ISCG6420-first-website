Web Development

Web development is the act of creating and maintaining websites and other web-based tools. It involves the use of many technologies to build and deliver web pages and applications to users. The scope of use is wide, allowing for a highly flexible, dynamic space for innovation and long term sustainability.

Web Technologies

Technology Description
HTML Defines the structure and content of a web page.
CSS Controls the appearance and layout of a web page.
JS Adds interactivity and behaviour to a web page.

Development tools

Technology Description
IDE A development environment for writing and managing code.
Git A version control system for tracking changes to files.
Web Browser An application for viewing and interacting with web pages.

Internet & WebSite Development
